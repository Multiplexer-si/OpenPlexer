# Provenance and scope

This page records what this repository contains, where its material comes from, and the license under which that material is released.

## What this repository contains

This repository holds the open-source foundation of OpenPlexer, and only these four parts:

1. The Claude Code and Codex adapters and hooks, and the local policy enforcement.
2. The Room protocol, and the formats of claims and decisions.
3. A single-team, self-hosted hub with basic policies.
4. The hash-chain format of the audit log, and a verifier.

Anything that is not one of these parts is not part of this repository. Building and checking this repository needs nothing outside it. Only regenerating the contracts and fixtures needs a checkout of the existing implementation.

The repository holds the contracts for all four parts today. It holds no implementation of them yet. The [roadmap](roadmap.md) gives the order of the work.

## What stays outside this repository

The existing implementation has more features than the four parts. The following features stay outside this repository, and no issue in this repository plans them:

- The dashboard.
- The TUI.
- The GitHub App and the server check.
- The write ledger.
- Sign-up.
- Invitations, and workspaces with more than one team.
- Notifications.
- Metrics.
- Attention.
- History search.
- Retention.

The inventory of the existing implementation lists the same features in its table of components that are out of scope.

Anyone can use this repository in a commercial product under the terms of Apache-2.0. A feature that such a product adds becomes part of this repository only through a pull request here, under the same license.

## Where the material comes from

The design ports the behavior of an existing TypeScript implementation. That implementation is not public.

| Material | Origin |
|---|---|
| The Go module, the layout, the build, the CI, and the documentation | Written for this repository |
| The schemas under `spec/` | Generated by [`tools/extract`](../tools/extract) from the type definitions of the existing implementation at commit `7d80045a`, or written for this repository where the contract README says so |
| The examples and the fixture inputs under `spec/` | Written for this repository, in `tools/extract` |
| The expected results of the fixtures | Computed by `tools/extract`, which runs the code of the existing implementation at commit `7d80045a` |
| Go code | None of it is ported yet |

No source code of the existing implementation is copied into this repository. The schemas and the expected results are data that `tools/extract` derives from it. [Regenerate the contracts and fixtures](../CONTRIBUTING.md#regenerate-the-contracts-and-fixtures) gives the commands.
